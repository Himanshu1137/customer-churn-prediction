PROJECT OVERVIEW

About This Project

An end-to-end machine-learning project for predicting telecom customer churn and presenting the result through a modern dashboard.

↗

🎯 Project Goal

Identify customers who may leave the service so retention teams can prioritize outreach and understand the main risk signals.

🧠 Machine Learning

The project compares Logistic Regression and Random Forest models, evaluates them using Accuracy and ROC-AUC, and selects the stronger model.

⚙️ ML Pipeline

Raw Data→Cleaning→Encoding→Training→Evaluation→Prediction

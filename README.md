# Customer Churn Prediction

Machine Learning based Customer Churn Prediction web application built with Python, FastAPI, Scikit-learn, HTML, CSS and JavaScript.

## Features
- Customer churn prediction
- Churn probability and risk level
- Responsive desktop and mobile UI
- FastAPI backend
- Machine Learning model integration

## Run Locally

1. Create virtual environment: py -3.11 -m venv .venv
2. Activate: .venv\Scripts\Activate.ps1
3. Install: python -m pip install -r backend\requirements.txt
4. Run: python -m uvicorn backend.main:app --reload
5. Open: http://127.0.0.1:8000
